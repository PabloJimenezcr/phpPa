# Catalogo profesional PHP

## Descripcion

Aplicacion educativa para mostrar y buscar productos utilizando PHP, HTML y CSS.

## Requisitos

- PHP compatible con la version utilizada
- Apache mediante XAMPP
- Visual Studio Code

## Instalacion

1. Copiar la carpeta semana14_php en C:\xampp\htdocs
2. Activar Apache en XAMPP
3. Abrir el navegador
4. Ingresar a http://localhost/semana14_php/public/

## Estructura

- public: punto de entrada y recursos publicos
- app/config: configuracion general
- app/data: datos de ejemplo
- app/controllers: logica de la aplicacion
- app/views: presentacion HTML

## Funcionalidades

- Mostrar productos
- Filtrar por nombre o categoria
- Mostrar precios y disponibilidad
- Adaptar la presentacion a diferentes pantallas
